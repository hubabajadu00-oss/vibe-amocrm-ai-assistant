# Двухконтурный ИИ-ассистент для диалогового окна AmoCRM (О-комплекс)

> **Тестовое задание на позицию:** Разработчик (Вайбкодинг & ИИ)  
> **Кандидат:** Пётр Измайлов  
> **Стек:** Claude Code, Cursor, Python (REST API), RAG Pattern, HTML5/CSS3/Vanilla JS  

---

## 1. Архитектура решения

Сервис решает ключевую задачу отдела продаж: при поступлении обращения клиента в AmoCRM он сверяется с корпоративной базой знаний и **одновременно формирует два независимых контура**:

1. **Блок 1 (Внешний контур — ответ клиенту):**  
   Вежливый, емкий и точный ответ на основе реальных тарифов, сроков и условий из базы знаний без галлюцинаций. Призывает к целевому действию (15-минутный звонок / демо-стенд).
   
2. **Блок 2 (Внутренний контур — подсказка менеджеру по допродажам):**  
   Инструкция для сейлз-менеджера в интерфейсе AmoCRM:
   * Релевантные опции допродаж (Upsell / Cross-sell);
   * Стратегия аргументации (почему клиенту выгодна интеграция или расширенный пакет);
   * Точный вопрос-триггер для выявления скрытых потребностей и повышения среднего чека.

---

## 2. Какие ИИ-инструменты помогли собрать сервис (Вайбкодинг)

* **Claude Code (CLI Agent):** Использовался как генеральный архитектор для быстрой декомпозиции ТЗ, проектирования структуры базы знаний (`knowledge_base.json`) и сборки легковесного Python REST-сервера без тяжелых внешних зависимостей.
* **Cursor (AI Code Editor):** Применялся для генерации интерактивного фронтенда в стилистике современных CRM-интерфейсов, оптимизации структуры DOM и валидации UX-сценариев менеджера.
* **Промпт-инжиниринг и RAG-паттерн:** Логика разделения потока на клиентский ответ и менеджерский апсейл построена на классическом RAG-принципе: семантический матчинг интента -> подтягивание контекста -> дуальная генерация.
